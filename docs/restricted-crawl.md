# 受限网站爬取

这是信息收集的起步功能：从一个已授权页面开始，发现普通站内链接，保存访问证据，
对取得的响应执行已有响应头检查，汇总静态表单与参数名称，并输出中文报告。

## 使用

```powershell
npm ci
npm run crawl -- http://127.0.0.1:5000/
```

网站需已运行，并在现有 `scope.local.json` 与 `http.local.json` 中被允许。
首次安装需要 `npm ci` 安装锁定版本的 HTML 解析依赖；后续只运行 crawl 即可。
命令行无需模型 API。OpenCode 重启后选择 `web-security-agent`，说：

```text
受限爬取 http://127.0.0.1:5000/，发现站内页面并检查响应头，给我中文总结。
```

Agent 使用 `authorized_web_crawl`，参数只有 URL，限制由本地文件控制。
普通“扫描一个 URL”仍使用原有单页入口，避免无意增加请求数。

## 默认限制

| 参数 | 默认 | 允许配置范围 |
| --- | ---: | --- |
| 页面任务数（包括失败任务） | 10 | 1–30 |
| 链接深度（起始页为 0） | 2 | 0–4 |
| 请求尝试总数（包括重定向、DNS/连接失败） | 20 | 1–60 |
| 请求尝试之间最小间隔 | 300 ms | 100–5000 ms |

没有 `configs/crawl.local.json` 时直接使用默认值。需要调整时参考
`configs/crawl.example.json` 创建本地文件；格式损坏或超出上限会拒绝启动，不会静默忽略。
本地配置不提交 Git，也不替代现有目标授权。

每个响应最多 256 KiB、一次 HTTP 请求最多 5 秒、每条链最多 5 次重定向；
若 HTTP 配置更严格，以更严格限制为准。请求总超时可终止持续输出小块数据的响应。
DNS 查询仍使用操作系统解析器，没有实现整个爬取任务的严格墙钟截止时间或 UI 取消按钮。
同一时刻只执行一个页面任务；最多记住 200 个候选 URL，每页最多提取 200 个链接。

## 发现与范围

- 使用 [parse5](https://parse5.js.org/) 按 HTML 解析规则识别 `a/area href` 和第一个 `base href`。
- 相对链接基于最终页面 URL 与 base 解析，去掉片段后去重；查询参数链接直接跳过，不删除参数后改访其他地址。
- 必须与最初起点同源：协议、主机、有效端口都一致。即使项目总体 Scope 同时允许两个站点，也不跨源跟进。
- 每个普通链接及每一跳重定向都重新检查 Scope；连接前仍经过原有解析 IP 检查和固定 IP 连接。
- 不解析脚本中的“链接”、注释或模板内容，不执行 JavaScript、不提交表单、不携带登录身份。
- 下载属性链接跳过。只有成功的 2xx、`text/html`、未压缩响应会继续提取链接；其他响应可以记录并检查头。
- GET 仍可能触发设计不当网站的业务操作，已知退出、删除等路径应放入项目 `denied_paths`。
- 当前不自动读取 sitemap/robots.txt，不做子域名枚举、目录字典猜测或参数探测。

## 结果与停止

每个取得的响应保存 EV 和单页中文报告，另生成 `reports/opencode/CRAWL-*.md` 汇总。
摘要默认不展示内部编号；汇总表保留证据引用。不会创建或推进 HYP。
汇总报告还会合并相同方法和 action 的表单，并列出其出现页面和参数名称；链接中的查询值、
表单默认值不会写入汇总。外部 action 只标记为非同源，不会被访问或获得授权。
停止原因包含队列处理完毕、达到页面上限、达到请求上限或存储失败。
跳过统计包含重复、深度上限、范围/同源/查询参数限制等。有限范围结束不表示覆盖整个网站。

`CRAWL_COMPLETED` 表示选中任务均已处理，仍可能因为预算或深度而只覆盖部分页面。
`CRAWL_PARTIAL` 表示有未完成任务或存储失败；失败页面不会被写成扫描通过。
汇总写入失败返回 `REPORT_ERROR`，工具结果仍保留已生成的证据及单页报告路径。
CLI 完成返回 0，失败或部分完成返回 2。

## 验证边界

自动化测试使用临时本地 HTTP 网站，验证同源、路径、重定向、参数跳过、去重、深度、
页面数、请求数、间隔、响应大小、超时和存储失败。本工具真实 OpenCode 会话调用待验证。
当前不会检测 SQL 注入、XSS、越权等主动漏洞；响应头复核和输入入口都不等于漏洞确认。
